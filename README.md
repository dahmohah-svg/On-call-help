# On-Call Board

A single-page planner for anaesthesia on-call teams. It assigns OT cases, APS reviews, emergency calls, preop assessments and list preparation to second and first on-call doctors, shows the shift as a timeline, and produces handover text to paste into the team chat.

- Open `index.html` in any browser (or host it with GitHub Pages).
- Edit `src/app.html`, then run `./build.sh` to rebuild `index.html`.
- Data is stored in the browser only (localStorage). Use ward/bed, not patient names or record numbers.
